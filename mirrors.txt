# MamboTTS 引擎整合包下载镜像配置（可选）
#
# 默认已内置四个官方源（ModelScope 双通道 / hf-mirror / HuggingFace），
# 安装时会自动测速选最快的，一般无需修改本文件。
#
# 什么时候需要改：四个源都慢/挂了，而你恰好有更快的镜像（如公司内网、
# 网盘直链、自己的对象存储）时，把 URL 按下面格式写进来即可，无需改代码。
#
# 格式：每行一个下载 URL 模板，{file} 会替换为整合包文件名
#       （GPT-SoVITS-v5-20261005nvidia50x0.7z 或 GPT-SoVITS-v5-20261005.7z）
# 以 # 开头的行是注释。写在最前面的源优先测速。
#
# 示例（取消注释并替换为你的镜像地址）：
# https://mirrors.example.com/gpt-sovits/{file}
